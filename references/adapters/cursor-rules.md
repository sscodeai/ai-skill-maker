# Cursor Rules Adapter

Use when the user wants `.cursor/rules` output.

## Mapping

- Split broad maintainer guidance into focused rule files.
- Put always-on project constraints in `.cursor/rules/project.mdc`.
- Put stack-specific rules in separate files when the repo has clear areas.
- Keep rules short and directly actionable.

## Caution

Cursor rules should not include long evidence ledgers. Preserve the full evidence model in the full project skill references.

# AGENTS.md Adapter

Use when the user wants repository-native instructions for agents that read `AGENTS.md`.

## Mapping

- Summarize the generated maintainer skill into `AGENTS.md`.
- Keep long detail in linked project docs or the generated skill references.
- Include verification commands, generated-file rules, and content style.
- Preserve evidence categories in compact form when useful.

## Caution

Do not treat `AGENTS.md` as a replacement for the generated skill unless the user explicitly wants repo-local instructions only.
